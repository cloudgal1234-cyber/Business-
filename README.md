# 🎤 Investor Pitch Simulator — סימולטור פגישת משקיעים

אפליקציית ווב בעברית (RTL מלא, רספונסיבית, מצב בהיר/כהה) שמכינה יזמים לפגישת משקיעים על בסיס האתר של העסק.

**הזרימה:** קליטת אתר (URL או הדבקת טקסט) → סיכום הבנת העסק → בחירת משקיע ואורך סשן → סימולציית שאלות עם מאמן אישי → דוח מוכנות.

## הרצה מהירה

```bash
npm install
npm run dev          # http://localhost:3000
```

זה הכול. **לא צריך מפתח API.** בלי מפתח, האפליקציה רצה ב**מצב דמו** עם מנוע מקומי שמבוסס על כללים.

### הפעלה עם Claude (מומלץ)

```bash
cp .env.example .env.local
# ערכו את .env.local והוסיפו: ANTHROPIC_API_KEY=sk-ant-...
npm run dev
```

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | בלי מפתח: מצב דמו. עם מפתח: ניתוח, שאלות, ציונים ודוח שמופקים ע״י Claude |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | דריסת המודל |
| `ANTHROPIC_EFFORT` | לפי משימה (`low` לציונים ולרמזים, `medium` לניתוח, לשאלות ולדוח) | דריסת רמת המאמץ (`low` / `medium` / `high`) |
| `READER_FALLBACK` | `false` | `true` מאפשר fallback דרך `r.jina.ai` לאתרים שחוסמים גישה או נבנים ב-JS. **שימו לב:** במצב הזה כתובת האתר נשלחת לשירות צד שלישי |

אם קריאה ל-Claude נכשלת (מפתח שגוי, רשת, מגבלת קצב), האפליקציה חוזרת אוטומטית למנוע המקומי ומציגה על כך הודעה. גם כשמוגדר מפתח, אפשר לבחור במסך הראשון "מצב דמו".

### פריסה

- **Vercel:** מייבאים את הריפו ומגדירים `ANTHROPIC_API_KEY` במשתני הסביבה. אין צורך בהגדרות נוספות.
- **כל שרת Node 18 ומעלה:** `npm run build && npm start`

## מה יש באפליקציה

1. **קליטת אתר במצב כפול**
   - **URL:** השרת שולף את דף הבית ועד 4 דפים מרכזיים (אודות / מחירים / שירותים / לקוחות), ומחלץ כותרות, טקסטים, מחירים וסימני משיכה.
   - **Fallback:** ניסיון בכתובת חלופית עם או בלי `www`; שירות קריאה חיצוני (אופציונלי, ראו למעלה); ואם האתר חוסם, האפליקציה מציעה מעבר להדבקת טקסט בלחיצה אחת.
   - **הדבקת טקסט:** לדפי נחיתה מקומיים, לטיוטות ולאתרים שדורשים התחברות.
   - **אבטחה:** השרת לא שולף כתובות פרטיות או מקומיות (הגנת SSRF, כולל בדיקה בכל הפניה). גודל התגובה וזמן ההמתנה מוגבלים.
   - **סיכום הבנת העסק:** מה העסק עושה, קהל היעד, המודל העסקי, התמחור, מה עובד באתר ומה חסר בו.
2. **סימולטור שאלות:** 6 קטגוריות (בעיה ופתרון, שוק ומתחרים, מודל עסקי, משיכה, שימוש בכסף, סיכונים). אפשר לבחור **אנג׳ל ידידותי** או **VC קשוח**, וסשן קצר (6 שאלות) או מלא (12). עונים בטקסט או **בקול** (Web Speech API בעברית), ואפשר לערוך את מה שהוקלט.
3. **מאמן כשנתקעים:**
   - כפתור "נתקעתי" נותן עזרה ב-3 רמות: מה המשקיע בודק, שלד לתשובה, ופתיח מוכן להשלמה (אפשר להכניס אותו לתשובה בלחיצה).
   - ציון נמוך מ-6 או "לא יודע" מעבירים אוטומטית ל**מצב מאמן**: הסבר למה התשובה לא תשכנע, שאלות מנחות, דוגמה לתשובה משופרת וכפתור **"נסה לענות שוב"**.
4. **פידבק לכל תשובה:** ציון 1–10 עם תג (חזק / טוב אבל חסר פירוט / דורש חיזוק), מה עבד ומה לחדד, תשובה משופרת, וכפתור **שאלת המשך** שבו המשקיע לוחץ על נקודה מהתשובה.
5. **דוח מוכנות:** ציון כללי (משקלל איכות וכיסוי של כל הקטגוריות), ציון לכל קטגוריה, 3 חוזקות, 3 נקודות חולשה עם **תשובות מוכנות לשינון**, שיפורים לאתר והכנה לפגישה. אפשר להעתיק את הדוח, לייצא Markdown או להדפיס ל-PDF, וגם לתרגל שוב רק את השאלות החלשות.

ההתקדמות נשמרת ב-`localStorage` של הדפדפן, כך שרענון לא מוחק את הסשן.

## מבנה הקוד

```
app/
  page.js                 # מכונת המצבים: input → profile → sim → report
  layout.js, globals.css  # RTL, פונט Heebo, ערכת צבעים (משקיע = אינדיגו, מאמן = ירוק)
  api/
    analyze/   # שליפת אתר / טקסט ← פרופיל עסק
    questions/ # שאלות מותאמות לפי משקיע ואורך
    evaluate/  # ציון, פידבק, מאמן ושאלת המשך
    hints/     # 3 רמות עזרה
    summary/   # דוח מוכנות
    status/    # האם Claude מוגדר
components/
  InputStage, ProfileSummary, Simulator, VoiceButton, Report, ui
lib/
  scraper.js       # שליפה עם cheerio, תתי-דפים, fallbacks והגנת SSRF
  llm.js           # מנוע Claude (@anthropic-ai/sdk, structured outputs עם JSON schema)
  local-engine.js  # מנוע דמו מקומי שמחזיר את אותו מבנה נתונים
  engine.js        # בוחר מנוע, ועובר למקומי אם יש שגיאה
  constants.js     # קטגוריות, פרסונות וספי ציון
```

שני המנועים (`llm.js` ו-`local-engine.js`) מחזירים בדיוק אותו מבנה נתונים, כך שהממשק לא תלוי במנוע שרץ.

**סטאק:** Next.js 14 (App Router), React 18, Tailwind CSS 3, cheerio, ו-Anthropic SDK.
